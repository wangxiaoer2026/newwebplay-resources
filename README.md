# New Web Play Resources

Player-friendly game guides, hub pages, tools, and checklists from [New Web Play](https://newwebplay.com/).

New Web Play focuses on practical pages for players: codes, maps, value lists, calculators, beginner routes, platform notes, and game-specific troubleshooting. This repository is a public index for the guides and tools that are useful to open again while playing.
